# GM Desk 🚀

Bem-vindo ao repositório do **GM Desk**!

Este é um projeto pessoal em desenvolvimento, construído para otimizar e facilitar o monitoramento do meu dia a dia. O objetivo principal deste programa é fornecer uma interface prática, limpa e rápida para verificar o status de diversos PDVs e identificar instantaneamente quais caixas estão offline.

## 🌟 Funcionalidades
- **Monitoramento em Tempo Real:** Verificação de status online/offline dos PDVs com apenas um clique.
- **Acesso VNC Embutido:** Conexão remota rápida para qualquer PDV da rede.
- **Gerenciamento de Perfil:** Importação e exportação da configuração de lista de caixas para sincronizar facilmente entre diferentes computadores.
- **Interface Moderna e Limpa:** Design focado em praticidade para não perder tempo com excesso de formulários na tela.

## 🛠️ Tecnologias Utilizadas
- **Rust (Tauri):** Motor principal de alta performance e baixo consumo de memória.
- **JavaScript & CSS:** Toda a lógica visual, modais e customizações da interface.

## ⚙️ Instalação (Windows)
Este projeto conta com compilação automática na nuvem usando o GitHub Actions!
Sempre que o código é atualizado, uma nova versão do `.exe` é gerada.

1. Vá na aba **Releases** deste repositório.
2. Baixe o arquivo de instalação para Windows.
3. Se desejar usar a versão totalmente portátil, extraia o `.exe` que não requer privilégios de administrador para usar na sua rede.
